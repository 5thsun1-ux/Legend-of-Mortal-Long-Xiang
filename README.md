## 2. 세부 게임 시스템 (Detailed Features)

### 1) 5개 국어 글로벌 로컬라이제이션
상단 언어 선택 바를 통해 한국어, 번체중문, 간체중문, 일본어, 영어 5개 언어로 실시간 전환됩니다.
- 타이틀 글자 섭취 애니메이션의 언어별 글자 자동 갱신
- 인게임 점수, 스테이지 안내, 적 피격 및 게임오버 메시지 번역
- 각 국가별 식문화를 반영한 12종 특수 닭요리 명칭 및 엔딩 크레딧 번역

### 2) 12단계 점진적 미로 스테이지
- 1막(11x11 초소형)부터 12막(23x23 초대형)까지 순차적으로 맵의 규모와 적 배치가 확장됩니다.
- 모든 스테이지는 고립된 구역 없이 100% 이동 가능한 폐쇄형 미로 구조로 설계 및 검증되었습니다.
- 각 스테이지마다 고유한 보너스 특수 닭요리가 등장합니다.

### 3) 아케이드 코너링 보정 및 즉각 반전
- 코너링 관용 범위: 교차로 중심에 정확히 1픽셀 단위로 도달하지 않고 앞뒤 약 14픽셀 범위에서 방향키를 미리 입력하더라도 벽에 걸리지 않고 자연스럽게 레인에 스냅되어 회전합니다.
- 자동 레인 중앙 정렬: 직선 구간 주행 시 통로 중심선으로 부드럽게 정렬되어 모서리 걸림을 방지합니다.
- 즉시 180도 반전: 이동 중 반대 방향키 입력 시 교차로를 거치지 않고 즉각 반대 방향으로 회두합니다.

### 4) 적 AI 및 3중 벽 충돌 방지 시스템
- 성설 (盛雪 / Sheng Xue): 플레이어를 향해 최단 거리로 직접 접근하는 직진 추격형 AI
- 화중선 (畫中仙 / Hua Zhong Xian): 플레이어 진행 방향의 앞 4타일을 계산하여 길목을 선점하는 매복형 AI
- 당포의 (唐布衣 / Tang Buyi): 성설의 위치를 기준으로 반대편 좌표를 노려 포위망을 좁히는 양동형 AI
- 조활 (趙活 / Zhao Huo): 플레이어와의 거리에 따라 추격과 자유 순찰을 전환하는 변칙형 AI
- 3중 벽 충돌 방지: 전방 벽 감지 정지, 레인 중심 잠금, 비정상 좌표 긴급 탈출 메커니즘을 적용하여 적이 벽(#)을 통과하는 현상을 원천 방지합니다.

### 5) 대기 화면 풀스크린 어트랙트 데모
게임 시작 전 대기 상태에서는 4종의 고화질 애니메이션이 스테이지 영역 전체에서 무한 순환 재생됩니다:
1. 제자리 입 벌림 루프 (Chomp Transparent)
2. 치킨 헌터 쇼케이스 (Chicken Hunter)
3. 움직이며 닭다리 먹는 애니메이션 (Moving)
4. 4방향 미로 주행 데모 (Maze Demo)
화면을 클릭하면 데모가 멈추고 해당 스테이지 시작 안내 창이 표시됩니다.

### 6) Web Audio API 내장 사운드 엔진
별도의 사운드 파일 다운로드 없이 브라우저 내장 오디오 신디사이저로 와카와카 섭취음, 특수 요리 획득음, 파워 치킨 활성화음, 적 포획음, 클리어 팡파르를 실시간 합성합니다.

## 4. GitHub 저장소 배포 및 실행 가이드 (Deployment Guide)

### 1) 로컬 브라우저 실행
- 저장소를 다운로드하거나 클론합니다.
- index.html 파일을 웹 브라우저(Chrome, Edge, Safari, Firefox 등)로 더블 클릭하여 실행합니다.
- 외부 인터넷 연결이나 웹 서버가 없어도 오프라인 상태에서 100% 정상 구동됩니다.

### 2) GitHub Pages 무료 웹 배포
- 본 저장소의 파일들을 본인의 GitHub Repository에 Push합니다.
- 저장소 페이지 상단의 Settings 메뉴로 이동합니다.
- 좌측 사이드바의 Pages 항목을 클릭합니다.
- Build and deployment 섹션에서 Branch를 main (또는 master)으로 설정하고, 폴더를 /(root)로 지정한 뒤 Save를 누릅니다.
- 배포 완료 후 제공되는 웹 페이지 주소( https://5thsun1-ux.github.io/Legend-of-Mortal-Long-Xiang/ )를 통해 전 세계 어디서나 웹 브라우저로 즉시 접속하여 플레이할 수 있습니다.
